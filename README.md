# RIT-MS Analysis Platform v2.0

현대적이고 직관적인 RIT-MS (Resonant Ion Trap Mass Spectrometry) 데이터 분석 플랫폼입니다. Cursor GUI 스타일을 반영한 아름다운 인터페이스와 강력한 분석 기능을 제공합니다.

## 🚀 주요 기능

### 📊 데이터 분석
- **단일 스펙트럼 분석**: 개별 RIT-MS 스펙트럼 시각화
- **오버레이 분석**: 여러 스펙트럼의 비교 분석
- **통계 분석**: 피크 검출, 노이즈 분석, 신호 품질 평가
- **데이터 테이블**: 원시 데이터의 표 형태 표시

### ⚡ 실시간 모니터링
- **실시간 데이터 수신**: TCP 소켓을 통한 실시간 데이터 스트리밍
- **연결 상태 모니터링**: 실시간 연결 상태 표시
- **데이터 시각화**: 실시간 데이터의 동적 업데이트
- **통계 정보**: 최대/최소 신호, 데이터 포인트 수 등

### 🎨 현대적인 UI/UX
- **Cursor 스타일 디자인**: 어두운 테마와 현대적인 색상 팔레트
- **확장/축소 가능한 사이드바**: 접을 수 있는 네비게이션 패널
- **탭 기반 인터페이스**: 체계적인 기능 분류
- **부드러운 애니메이션**: 확장/축소 모션과 전환 효과

### 📁 파일 관리
- **다양한 형식 지원**: CSV, Excel (.xlsx) 파일 지원
- **자동 데이터 로드**: 파일 선택 시 즉시 분석 준비
- **플롯 저장**: PNG, PDF 형식으로 분석 결과 저장

## 🛠️ 설치 및 실행

### 요구사항
- Python 3.7+
- PyQt5
- pandas, matplotlib, numpy, scipy

### 설치
```bash
pip install -r requirements.txt
```

### 실행
```bash
python main_layer1_gui.py
```

## 📋 사용법

### 1. 파일 로드
- 사이드바의 "📂 파일 열기" 버튼 클릭
- CSV 또는 Excel 파일 선택
- 자동으로 데이터가 로드되고 첫 번째 스펙트럼이 표시됩니다

### 2. 스펙트럼 분석
- **단일 스펙트럼**: "📈 단일 스펙트럼" 버튼으로 현재 데이터 플롯
- **오버레이**: "🔄 오버레이 분석" 버튼으로 여러 데이터셋 비교
- **통계 분석**: "📊 통계 분석" 버튼으로 고급 분석 수행

### 3. 실시간 모니터링
- "⚡ 실시간" 탭으로 이동
- "연결" 버튼을 클릭하여 실시간 데이터 스트림 시작
- 실시간 데이터와 통계 정보 확인

### 4. 데이터 탐색
- "📋 데이터" 탭에서 원시 데이터 테이블 확인
- "📊 분석" 탭에서 상세한 분석 결과 확인

## 🏗️ 아키텍처

### 주요 모듈
- `main_layer1_gui.py`: 메인 GUI 애플리케이션
- `rit_data_loader.py`: 데이터 로딩 및 처리
- `rit_plotter.py`: 스펙트럼 플로팅 기능
- `realtime_communication.py`: 실시간 통신 및 모니터링

### 클래스 구조
```
ModernRITMSWindow
├── SidebarWidget (확장/축소 가능한 사이드바)
└── MainContentWidget
    └── QTabWidget
        ├── RITPlotterWidget (스펙트럼 플로팅)
        ├── RealtimeMonitorWidget (실시간 모니터링)
        ├── DataAnalysisWidget (데이터 분석)
        └── QTableWidget (데이터 테이블)
```
